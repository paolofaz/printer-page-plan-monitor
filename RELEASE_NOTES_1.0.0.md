# Printer Page Plan Monitor for HP Instant Ink v1.0.0

First public release of the Home Assistant custom integration.

Highlights:
- local subscription page-counter monitoring;
- monthly and rollover page tracking;
- configurable rollover cap;
- automatic renewal-cycle handling;
- CMYK ink levels;
- persistent state and diagnostics;
- English and Italian translations;
- original vendor-neutral branding.
